## Decisions (recommended options, applied on "implement", 2026-11-05)
- **174** - lists order and filter by the date the column shows (`created_at`); the column itself is unchanged.
- **183** - a department in use is **blocked** from deletion (not cleared from employees).
- **201** - the popup **stays mandatory** but offers Change password and Log out, and does not open on `/change-password`.

## Solution
- **166** - `AppConfigurationService::resolveSurfaceLogos`: for a tenant branded as itself the favicon is its own Square mark, else one of its own logos (mobile, sidebar, document, mail), else a 64x64 PNG placeholder with its initial - never the host's. Host and certified partners unchanged. Admin Branding note lists the missing square mark.
- **171** - not reproducible on this branch (the sheet already says Fixed): a test drives the real Partner Profile page from Suspended to Active / Inactive / OnBoarding and passes. Kept as a regression test.
- **174** - `RequestApplicationService::getPreQualificationList` sorts/filters on `created_at` (default desc, `id` tie-break); `MyApplicationService::preQualificationList` orders `created_at` desc, `id` desc.
- **175** - Store/UpdateLenderRequest: `website` is `url:http,https`; `NormalizesLenderWebsite` adds `https://` to a site typed without a scheme.
- **176** - `FundingSequencingService` sorts `amount_range` by min then max as numbers.
- **182** - new `StoreDepartmentRequest` (unique per partner, case-insensitive, trimmed).
- **183** - `DepartmentService::destroy` throws `DepartmentInUseException` (422 with the count) while the partner's employees use the name; 404 for another partner's department. Admin: confirm dialog, API reason shown, edit form keeps an orphaned department as an option.
- **184** - category sort by `blog_categories.name` (subquery).
- **185** - blog list always ends ORDER BY with `blogs.id desc`.
- **186** - admin `BlogEdit`: the new tag id goes into the field as a string (the options' type).
- **199** - "At least one lowercase / uppercase letter / number" - borrower **and admin** reset-password pages (same typos).
- **201** - borrower `ProfileCompleteCheckModal`: Change password and Log out buttons; not shown on `/change-password`.
