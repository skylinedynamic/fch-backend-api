# FCH WLP Funding Request Guide

**Version:** v1.0
**Classification:** Partner-Safe / WLP-Facing Knowledge

## Purpose

This guide covers a client's funding journey end to end: how a WLP submits a funding request and tracks it through to a decision.

## Submitting a funding request

A WLP submits a funding request for a client from the **Clients** section of the dashboard:

1. Open the client's record from the Clients list.
2. Select **New Funding Request**.
3. Fill in the requested amount and funding purpose.
4. Submit the request for review.

## Checking a funding request's status

Once submitted, a funding request moves through these statuses: **Submitted → Under Review → Approved / Declined**.

A WLP can check the current status from the client's record under the **Funding Requests** tab. The assistant should tell the WLP where to look for status rather than guessing an individual request's outcome, since that is client-specific data the assistant does not have direct access to.

**Take Me There**
Then select the client's **Funding Requests** tab.
